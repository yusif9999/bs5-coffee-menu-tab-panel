# Bootstrap Tabbed Coffee Menu

A responsive local coffee house landing page built primarily to demonstrate how to create dynamic tab panels using lists (List Group) in Bootstrap 5. 

## 📌 Focus of the Project

The main technical objective of this project is to practice and implement **Tab Panels built with Lists**. It features a seamless, interactive transition between "Hot Drinks" and "Cold Drinks" menus without reloading the page, utilizing Bootstrap's `list-group` and `tab-content` classes.

## 🚀 Key Features

- **Dynamic Tab Navigation:** Interactive menu switching using Bootstrap list groups and tab panes.
- **Responsive Grid Layout:** Mobile-friendly structural design using the Bootstrap grid system.
- **Data Presentation:** A "Coffee Intensity Guide" built with Bootstrap's animated progress bars.
- **Modern UI Components:** Practical usage of alerts, badges, and breadcrumb navigation.

## 🛠️ Built With

* HTML5 - Semantic page structure
* CSS3 - Custom styling (`style.css`)
* Bootstrap 5.3 - Frontend framework for responsive design and tab functionality
* Bootstrap Icons & FontAwesome - Scalable vector icons
